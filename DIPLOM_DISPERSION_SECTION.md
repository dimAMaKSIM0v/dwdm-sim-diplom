## 1.5 Дисперсия в оптических волокнах и ее влияние на качество сигнала

Дисперсия является одним из ключевых факторов, ограничивающих дальность и скорость передачи в оптических системах связи. Она приводит к уширению импульсов и, как следствие, к межсимвольной интерференции, что снижает качество принимаемого сигнала [5,6].

### 1.5.1 Хроматическая дисперсия

Хроматическая дисперсия (ХД) возникает вследствие зависимости показателя преломления волокна от длины волны. Различные спектральные компоненты оптического сигнала распространяются с разными скоростями, что приводит к уширению импульса во времени [5].

Коэффициент хроматической дисперсии D(λ) зависит от длины волны и типа волокна. Для расчетов используется линейная аппроксимация:

```
D(λ) = D₀ + S₀ · (λ - λ₀)  [пс/(нм·км)]
```

где:
- D₀ – коэффициент дисперсии на опорной длине волны λ₀ = 1550 нм [пс/(нм·км)]
- S₀ – наклон дисперсии [пс/(нм²·км)]
- λ – длина волны канала [нм]

Накопленная хроматическая дисперсия вдоль линии рассчитывается как алгебраическая сумма:

```
D_total = Σ D(λ, тип_i) · L_i  [пс/нм]
```

где L_i – длина i-го участка волокна [км].

Важной особенностью ХД является возможность компенсации: положительная и отрицательная дисперсия могут частично компенсировать друг друга при последовательном соединении участков с разными типами волокон [5].

**Таблица 3 – Коэффициенты хроматической дисперсии для различных типов волокон**

| Тип волокна | D₀ @ 1550 нм, пс/(нм·км) | S₀, пс/(нм²·км) | Описание |
|-------------|--------------------------|-----------------|----------|
| G.652 (SMF) | 17.0 | 0.067 | Стандартное одномодовое волокно |
| G.653 (DSF) | 0.0 | 0.075 | Волокно со смещенной дисперсией |
| G.654 | 18.0 | 0.020 | Волокно со сдвинутой отсечкой |
| G.655 (NZ-DSF) | 4.0 | 0.045 | Ненулевая дисперсионная смещенная |
| G.656 | 7.0 | 0.045 | Широкополосное NZ-DSF |
| G.657 | 17.0 | 0.067 | Изгибоустойчивое (как G.652) |

*Источник: ITU-T G.652-G.657, Corning SMF-28 datasheet*

Уширение импульса от хроматической дисперсии определяется выражением:

```
τ_CD = |D_total| · Δλ_RMS  [пс]
```

где Δλ_RMS – среднеквадратичная спектральная ширина источника излучения [нм].

Спектральная ширина зависит от типа лазера:
- DFB (Distributed Feedback): Δλ ≈ 0.0005 нм – узкий спектр
- EML (Electro-absorption Modulated Laser): Δλ ≈ 0.002 нм – средний спектр
- FP (Fabry-Perot): Δλ ≈ 2.0 нм – широкий спектр (многомодовый)

Для высокоскоростных магистральных линий применяются лазеры с узким спектром (DFB, EML), что минимизирует влияние хроматической дисперсии [7].

### 1.5.2 Поляризационная модовая дисперсия

Поляризационная модовая дисперсия (ПМД) возникает из-за двулучепреломления оптического волокна. Две ортогональные поляризационные моды распространяются с различными скоростями, что приводит к разности групповых задержек (DGD – Differential Group Delay) [6].

В отличие от хроматической дисперсии, ПМД является случайной величиной, зависящей от механических напряжений, температуры и изгибов волокна. Для инженерных расчетов используется статистический подход.

Накопленная ПМД рассчитывается по методу RSS (Root Sum Square) согласно ITU-T G.691:

```
PMD_total = √(Σ (D_PMD_i · √L_i)²)  [пс]
```

где D_PMD_i – коэффициент ПМД для i-го участка [пс/√км].

**Таблица 4 – Коэффициенты ПМД для различных типов волокон**

| Тип волокна | D_PMD, пс/√км | Примечание |
|-------------|---------------|------------|
| G.652 (современный) | 0.10 | Типовое значение для новых кабелей |
| G.653 | 0.50 | Старые кабели могут иметь высокую ПМД |
| G.654 | 0.20 | 0.1-0.2 пс/√км |
| G.655 | 0.10 | Современные < 0.1 пс/√км |
| G.656 | 0.10 | < 0.1 пс/√км |
| G.657 | 0.10 | < 0.1 пс/√км |

*Источник: ITU-T G.691, Приложение A*

### 1.5.3 Лимиты дисперсии и критерии работоспособности

Максимально допустимая накопленная дисперсия зависит от скорости передачи и типа приемника. Превышение лимита приводит к увеличению коэффициента битовых ошибок (BER) и деградации качества канала [7].

**Таблица 5 – Лимиты дисперсии для различных битрейтов**

| Битрейт | Модуляция | Лимит ХД, пс/нм | Лимит ПМД, пс | Тип приемника |
|---------|-----------|-----------------|---------------|---------------|
| 2.5 Гбит/с | NRZ | 18000 | 40 | Прямое детектирование |
| 10 Гбит/с | NRZ | 800 | 10 | Прямое детектирование |
| 40 Гбит/с | NRZ | 60 | 2.5 | Прямое детектирование |
| 100 Гбит/с | DP-QPSK | 1000 | 1 | Когерентный с DSP |
| 400 Гбит/с | DP-16QAM | 2000 | 0.25 | Когерентный с DSP |

*Источник: ITU-T G.957, G.691, G.695; IEEE 802.3ba*

Для систем с прямым детектированием (2.5G, 10G, 40G) лимиты дисперсии жесткие, что требует тщательного выбора типа волокна и длины линии. Для когерентных систем (100G, 400G) с электронной компенсацией дисперсии (DSP) лимиты значительно выше, что позволяет строить более протяженные линии без компенсации дисперсии [7].

Эмпирическое правило для оценки лимита ПМД:

```
PMD_limit ≈ 0.1 · T_bit = 100 / bitrate_Gbps  [пс]
```

где T_bit – битовый интервал [пс].

Это соответствует штрафу по мощности ~1 дБ для NRZ модуляции.

### 1.5.4 Уширение импульса и комбинированное влияние дисперсии

Для гауссовых импульсов уширение от различных видов дисперсии комбинируется по правилу квадратичного сложения:

```
σ_out² = σ_in² + τ_CD² + τ_PMD²
```

где:
- σ_in – среднеквадратичная ширина входного импульса [пс]
- σ_out – среднеквадратичная ширина выходного импульса [пс]
- τ_CD – уширение от хроматической дисперсии [пс]
- τ_PMD – уширение от поляризационной модовой дисперсии [пс]

Для модуляции NRZ (Non-Return-to-Zero) входная ширина импульса определяется по критерию Найквиста:

```
FWHM ≈ 0.44 · T_bit
σ_in ≈ FWHM / 2.355 ≈ 0.187 · T_bit
```

где FWHM (Full Width at Half Maximum) – ширина импульса на полувысоте, T_bit – битовый интервал.

При сохранении энергии импульса уширение приводит к уменьшению пиковой мощности:

```
P_peak_out = P_peak_in · (σ_in / σ_out) · 10^(-A/10)
```

где A – суммарные потери в линии [дБ].

Это явление критично для систем с прямым детектированием, где пороговое решение принимается по амплитуде сигнала [7].

### 1.5.5 Методы компенсации дисперсии

Для протяженных линий с высокими скоростями передачи применяются методы компенсации дисперсии:

1. **DCF (Dispersion Compensating Fiber)** – волокно с отрицательной дисперсией, компенсирующее накопленную положительную дисперсию стандартного волокна. Недостаток – дополнительные потери (~0.5 дБ/км DCF) [5].

2. **DCM (Dispersion Compensation Module)** – модуль на основе DCF или решеток Брэгга, устанавливаемый в узлах. Обеспечивает компенсацию без изменения линейного тракта [5].

3. **EDC (Electronic Dispersion Compensation)** – электронная компенсация в приемнике с использованием DSP (Digital Signal Processing). Применяется в когерентных системах 100G/400G. Позволяет компенсировать дисперсию до 10000+ пс/нм без дополнительных оптических компонентов [7].

4. **Выбор типа волокна** – использование волокон с низкой дисперсией (G.655, G.656) вместо стандартного G.652 снижает накопленную дисперсию в 4-5 раз.

В разработанном приложении реализован расчет накопленной хроматической и поляризационной модовой дисперсии с проверкой соответствия лимитам для заданного битрейта. Это позволяет на этапе проектирования оценить необходимость применения методов компенсации дисперсии.

## Дополнение к формулам

### Формула групповой задержки

Групповая задержка определяет время распространения сигнала по волокну:

```
τ_g = (L · n_g) / c  [с]
```

где:
- L – длина волокна [м]
- n_g – групповой показатель преломления (безразмерный)
- c = 299 792 458 м/с – скорость света в вакууме

Для волокон типа G.652 на длине волны 1550 нм: n_g ≈ 1.4675, что соответствует задержке ~5 мкс/км или ~200 км/мс.

Групповой показатель преломления связан с фазовым показателем:

```
n_g = n - λ · dn/dλ
```

где n – фазовый показатель преломления.
