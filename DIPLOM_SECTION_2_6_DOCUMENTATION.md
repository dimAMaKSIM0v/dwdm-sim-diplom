## 2.6 Документация программного комплекса

В рамках разработки приложения создан комплект технической документации, обеспечивающий полноту описания программного продукта и возможность его дальнейшего развития и сопровождения. Документация включает три основных раздела: архитектуру системы, программный интерфейс (API) и физико-математические модели.

### Архитектура программного комплекса

Документ «Архитектура DWDM Network Simulator» (Приложение В) описывает структурную организацию приложения, принципы проектирования и взаимодействие компонентов. Приложение построено по трехслойной архитектуре с четким разделением ответственности между уровнями представления (GUI), бизнес-логики (Core) и данных (Models).

Документация архитектуры включает:
- Обзор структуры проекта и организации модулей
- Описание слоев приложения и их взаимодействия
- Модели данных (Network, Node, Fiber, Channel, Equipment)
- Компоненты бизнес-логики (менеджеры, калькуляторы, симуляционный движок)
- Графический интерфейс (PyQt5, Folium, Matplotlib)
- Применяемые паттерны проектирования (Separation of Concerns, Single Responsibility, Dependency Injection)
- Потоки данных и механизмы расширяемости

Архитектурная документация позволяет разработчикам быстро ориентироваться в кодовой базе и обеспечивает основу для дальнейшего развития функционала.

### Программный интерфейс (API)

Документ «API Documentation» (Приложение Г) предоставляет детальное описание программного интерфейса для разработчиков, желающих расширить или интегрировать симулятор с внешними системами.

API документация охватывает:
- Модели данных с описанием атрибутов и методов (Network, Node, Fiber, Channel, Equipment)
- Калькуляторы физических параметров (DispersionCalculator, AttenuationCalculator, PowerBudgetCalculator, AmplifierPlacer, FrequencyPlanCalculator)
- Менеджеры бизнес-логики (TopologyManager, TopologyAnalyzer, TrafficManager, SimulationManager)
- Утилиты импорта/экспорта (ProjectIO)
- Примеры программного использования API для создания сетей, расчета параметров и анализа результатов

Наличие API документации обеспечивает возможность программной интеграции симулятора в автоматизированные системы проектирования и позволяет создавать пользовательские расширения без модификации базового кода.

### Физико-математические модели

Документ «Физические модели и математика» (Приложение Д) содержит полное описание физических явлений, математических формул и допущений, используемых в расчетных модулях приложения.

Документация физических моделей включает:
- Хроматическая дисперсия: коэффициенты для типов волокон G.652-G.657, формулы накопления, лимиты для различных битрейтов, уширение импульса
- Поляризационная модовая дисперсия: коэффициенты ПМД, статистический метод накопления (RSS), лимиты согласно ITU-T G.691
- Затухание в волокне: коэффициенты затухания, потери на сварках и разъемах, расчет числа соединений
- Оптический бюджет мощности: энергетический баланс, запас по мощности, критерии работоспособности канала
- Уширение импульса: квадратичное сложение вкладов ХД и ПМД, влияние спектральной ширины источника
- Групповая задержка: расчет времени распространения сигнала
- Ссылки на стандарты ITU-T (G.652-G.657, G.691, G.694.1, G.957) и научную литературу (Agrawal, Ramaswami)

Физико-математическая документация обеспечивает прозрачность расчетных методик и позволяет верифицировать корректность результатов моделирования путем сравнения с аналитическими выкладками и стандартами отрасли.

### Руководство пользователя

Документ «Руководство пользователя» (Приложение Е) предназначен для конечных пользователей приложения и содержит пошаговые инструкции по работе с программным комплексом.

Руководство включает:
- Системные требования и процедуру установки
- Описание интерфейса приложения и панелей инструментов
- Инструкции по созданию топологии (узлы, волоконные линии, DWDM-каналы, оборудование)
- Настройку параметров волокна, каналов и оборудования
- Алгоритм автоматического размещения усилителей
- Запуск симуляции и интерпретацию результатов
- Анализ результатов: таблицы расчетов, графики дисперсии, глазковые диаграммы, профиль мощности
- Сохранение и загрузку проектов, экспорт результатов в Excel
- Примеры типовых сценариев использования (простая линия, кольцевая сеть, влияние типа лазера)
- Раздел часто задаваемых вопросов и устранения неполадок
- Горячие клавиши и дополнительные ресурсы

Руководство пользователя обеспечивает быстрое освоение функционала приложения и служит справочным материалом при решении практических задач проектирования DWDM-сетей.

Комплект технической документации в совокупности обеспечивает полноту описания разработанного программного комплекса с точки зрения архитектуры, программной реализации, физических моделей и практического применения.

## Рекомендации по адаптации .md файлов для диплома

### 1. Убрать markdown-специфичные элементы:
- Эмодзи (📑, ✅, ❌, ⚠️)
- Блоки кода с подсветкой синтаксиса (заменить на листинги)
- Ссылки на другие .md файлы (заменить на ссылки на приложения)

### 2. Адаптировать заголовки:
```markdown
# API Documentation - DWDM Network Simulator
```
→
```
ПРИЛОЖЕНИЕ Г
(справочное)
Программный интерфейс (API) DWDM Network Simulator
```

### 3. Таблицы оставить как есть (Word хорошо их импортирует)

### 4. Код-блоки оформить как листинги:
```markdown
```python
from core.models.network import Network
network = Network(name="My DWDM Network")
```
```
→
```
Листинг Г.1 – Создание объекта сети
from core.models.network import Network
network = Network(name="My DWDM Network")
```

### 5. Ссылки на стандарты оставить как есть (это плюс для диплома)
