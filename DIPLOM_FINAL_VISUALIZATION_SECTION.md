## Финальный вариант: Полное описание вкладки визуализации

Для комплексного анализа параметров канала в приложении реализована специализированная вкладка визуализации, открываемая при выборе канала из таблицы. Вкладка объединяет три основных блока информации:

**Блок энергетического бюджета** отображает профиль мощности вдоль трассы канала. График показывает изменение уровня оптической мощности на каждом участке линии с учетом затухания в волокне, потерь на сварках и разъемах, а также усиления в EDFA. На графике отмечены:
- Начальная мощность передатчика (P_tx)
- Пороги минимальной мощности для каждого типа оборудования
- Точки установки усилителей с указанием коэффициента усиления
- Итоговая мощность на входе приемника (P_rx)
- Чувствительность приемника (S_rx) и запас по мощности

Профиль мощности позволяет визуально контролировать, что уровень сигнала не опускается ниже критических значений на всем протяжении линии, и оценить корректность размещения усилителей.

**Блок анализа дисперсии** содержит два графика для оценки влияния хроматической и поляризационной модовой дисперсии на форму сигнала:

*График уширения импульса* показывает входной (σ_in) и выходной (σ_out) импульсы относительно битового интервала T_bit. Входной импульс представлен гауссовой функцией с шириной, определяемой битрейтом канала. Выходной импульс отображает результат уширения от накопленной дисперсии. Уширение рассчитывается по формуле квадратичного сложения:

σ²_out = σ²_in + τ²_CD + τ²_PMD

где τ_CD – уширение от хроматической дисперсии [пс], τ_PMD – уширение от поляризационной модовой дисперсии [пс].

*Глазковая диаграмма (Eye Diagram)* строится путем наложения множества битовых последовательностей (100-200 периодов) с учетом уширения импульса. Диаграмма позволяет оценить два ключевых параметра качества канала:
- Вертикальное открытие глаза – запас по амплитуде сигнала для корректного детектирования
- Горизонтальное открытие глаза – временное окно, в котором возможно надежное стробирование

"Закрытие глаза" (уменьшение вертикального и горизонтального открытия) указывает на деградацию качества сигнала от дисперсии. При закрытии более 50% рекомендуется применение DCM (модулей компенсации дисперсии), при закрытии более 70% – переход на когерентную модуляцию с электронной компенсацией (EDC) [7].

**Блок численных параметров** отображает сводную таблицу с ключевыми характеристиками канала:
- Длина линии и количество усилительных участков
- Суммарное затухание и запас по мощности
- Накопленная хроматическая дисперсия (ХД) и лимит для заданного битрейта
- Накопленная поляризационная модовая дисперсия (ПМД) и лимит
- Процент использования лимитов дисперсии с цветовой индикацией (зеленый/желтый/красный)
- Рекомендации по компенсации дисперсии или изменению параметров канала

Комплексное представление энергетического бюджета, формы сигнала и численных параметров в одной вкладке позволяет инженеру быстро оценить работоспособность канала и принять обоснованное решение о необходимости модификации параметров на этапе проектирования.

## Альтернативный вариант: Более краткий (если нужно сэкономить место)

Для комплексного анализа параметров канала реализована вкладка визуализации, объединяющая три блока:

**Профиль мощности** показывает изменение уровня оптической мощности вдоль трассы с учетом затухания, потерь и усиления в EDFA. График отмечает начальную мощность передатчика, точки установки усилителей, итоговую мощность на приемнике и запас по мощности.

**Анализ дисперсии** включает график уширения импульса (входной σ_in и выходной σ_out относительно битового интервала T_bit) и глазковую диаграмму (Eye Diagram). Уширение рассчитывается по формуле σ²_out = σ²_in + τ²_CD + τ²_PMD. "Закрытие глаза" более 50% указывает на необходимость применения DCM, более 70% – на переход к когерентной модуляции с EDC [7].

**Таблица параметров** отображает длину линии, затухание, запас по мощности, накопленную ХД и ПМД, лимиты для заданного битрейта, процент использования лимитов с цветовой индикацией и рекомендации по компенсации.

Комплексное представление энергетического бюджета, формы сигнала и численных параметров позволяет быстро оценить работоспособность канала на этапе проектирования.

## Формулы для редактора Word

**Уширение импульса:**
```
σ²ₒᵤₜ = σ²ᵢₙ + τ²_CD + τ²_PMD
```

**Если добавляете детали расчета τ_CD:**
```
τ_CD = |D_total| · Δλ_RMS
```

**Если добавляете детали расчета τ_PMD:**
```
τ_PMD = PMD_total  (уже рассчитана по методу RSS)
```
