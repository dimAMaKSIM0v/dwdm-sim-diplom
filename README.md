# DWDM Network Simulator

Приложение для моделирования и анализа первичных сетей связи на базе технологии DWDM (Dense Wavelength Division Multiplexing).

## 🎯 Возможности

- **Визуальное проектирование топологии** - интерактивная карта с узлами и волоконными линиями
- **Физическое моделирование** - расчет хроматической и поляризационной дисперсии, затухания, бюджета мощности
- **Частотный план** - автоматическое распределение каналов по сетке ITU-T
- **Размещение усилителей** - автоматический расчет позиций EDFA
- **Анализ трафика** - моделирование потоков данных между узлами
- **Визуализация дисперсии** - графики уширения импульсов и групповой задержки
- **Экспорт результатов** - сохранение схем и отчетов в JSON/Excel

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск приложения

```bash
python main.py
```

### Загрузка примера

```bash
python main.py --project examples/test_scheme_rf_backbone.json
```

## 🎓 Применение

Проект разработан для:

- Анализа влияния дисперсии на качество сигнала

## ⚠️ Ограничения

Симулятор **не учитывает**:
- Нелинейные эффекты (SPM, XPM, FWM)
- Шум усилителей (ASE)
- Межсимвольную интерференцию от фильтров
- Стимулированное рассеяние (SRS, SBS)

Подробнее см. [PHYSICS.md](PHYSICS.md#допущения-и-ограничения-модели)
