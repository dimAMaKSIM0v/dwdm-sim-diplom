# DWDM Network Simulator

Приложение для моделирования первичных сетей связи на базе DWDM.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Текущая структура

```text
PROTO/
  main.py
  requirements.txt
  assets/
  core/
  gui/
  utils/
  examples/
```

`examples/test_scheme_rf_backbone.json` оставлен для кнопки загрузки тестовой схемы в UI.
