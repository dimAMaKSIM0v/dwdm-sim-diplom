## Вариант 1: Подробное описание вкладки визуализации

Для наглядной демонстрации влияния дисперсии на качество сигнала в приложении реализована специализированная вкладка визуализации. Вкладка открывается при нажатии кнопки "Показать визуализацию" для выбранного канала и содержит два основных графика:

**График уширения импульса** отображает форму оптического импульса на входе и выходе линии. Входной импульс представлен гауссовой функцией с шириной σ_in, определяемой битрейтом канала. Выходной импульс показывает результат уширения от накопленной дисперсии с шириной σ_out. На графике также отмечен битовый интервал T_bit, позволяющий визуально оценить степень межсимвольной интерференции.

Уширение импульса рассчитывается по формуле квадратичного сложения:

σ²_out = σ²_in + τ²_CD + τ²_PMD

где τ_CD – уширение от хроматической дисперсии [пс], τ_PMD – уширение от поляризационной модовой дисперсии [пс].

**Глазковая диаграмма (Eye Diagram)** строится путем наложения множества битовых последовательностей (обычно 100-200 периодов) с учетом уширения импульса. Диаграмма позволяет оценить два ключевых параметра качества канала:
- Вертикальное открытие глаза – запас по амплитуде сигнала для корректного детектирования
- Горизонтальное открытие глаза – временное окно, в котором возможно надежное стробирование

"Закрытие глаза" (уменьшение вертикального и горизонтального открытия) указывает на деградацию качества сигнала от дисперсии. При закрытии более 50% рекомендуется применение DCM (модулей компенсации дисперсии), при закрытии более 70% – переход на когерентную модуляцию с электронной компенсацией (EDC) [7].

Вкладка визуализации также отображает численные параметры канала: накопленную ХД и ПМД, лимиты для заданного битрейта, процент использования лимита и рекомендации по компенсации. Это позволяет инженеру принять обоснованное решение о необходимости модификации параметров канала на этапе проектирования.

## Вариант 2: Краткое описание (если нужно сэкономить место)

Для визуальной оценки влияния дисперсии в приложении реализована вкладка визуализации, открываемая кнопкой "Показать визуализацию" для выбранного канала. Вкладка содержит два графика:

**График уширения импульса** показывает входной (σ_in) и выходной (σ_out) импульсы относительно битового интервала T_bit. Уширение рассчитывается по формуле σ²_out = σ²_in + τ²_CD + τ²_PMD, где τ_CD и τ_PMD – уширение от хроматической и поляризационной модовой дисперсии.

**Глазковая диаграмма (Eye Diagram)** строится наложением множества битовых последовательностей и показывает запас по амплитуде (вертикальное открытие) и времени (горизонтальное открытие). "Закрытие глаза" более 50% указывает на необходимость применения DCM, более 70% – на переход к когерентной модуляции с EDC [7].

Вкладка также отображает численные параметры: накопленную ХД и ПМД, лимиты, процент использования и рекомендации по компенсации.

## Рекомендации по выбору варианта

**Используйте Вариант 1 (подробный)**, если:
- Визуализация – ключевая фишка приложения
- Нужно показать глубину проработки функционала
- Объем главы 2 нужно увеличить для баланса с главой 1

**Используйте Вариант 2 (краткий)**, если:
- Нужен баланс между детальностью и объемом
- Визуализация – важная, но не центральная функция
- Стандартный объем НИР

**Используйте Вариант 3 (минимальный)**, если:
- Жесткие ограничения по объему
- Визуализация упоминается для полноты картины
- Основной акцент на расчетах, а не на интерфейсе

## Формулы в правильном формате для Word

Если используете редактор формул Word:

**Уширение импульса:**
```
σ²ₒᵤₜ = σ²ᵢₙ + τ²_CD + τ²_PMD
```

**Уширение от ХД (если добавляете):**
```
τ_CD = |D_total| · Δλ_RMS
```

**Накопленная ХД (уже есть в тексте):**
```
D_total = Σ D(λ,тип_i) · L_i
```

**Накопленная ПМД (уже есть в тексте):**
```
PMD_total = √(Σ (D_PMD_i · √L_i)²)
```
