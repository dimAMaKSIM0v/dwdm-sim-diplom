# Влияние SNR на глазковую диаграмму (Eye Diagram)

## Обзор

В систему добавлена поддержка визуализации влияния отношения сигнал/шум (SNR) на глазковую диаграмму. Это позволяет более реалистично оценить качество сигнала на приемной стороне DWDM-линии.

## Физическая модель

### Связь OSNR и SNR

**OSNR (Optical Signal-to-Noise Ratio)** — отношение оптической мощности сигнала к мощности оптического шума в эталонной полосе 12.5 ГГц (0.1 нм):

```
OSNR = P_signal / P_noise [в линейных единицах]
OSNR_dB = 10 · log₁₀(OSNR) [в дБ]
```

**SNR (Signal-to-Noise Ratio)** — отношение электрической мощности сигнала к мощности электрического шума после фотодетектора:

```
SNR ≈ OSNR · (B_ref / B_electrical)
```

где:
- `B_ref` = 12.5 ГГц — эталонная полоса для измерения OSNR
- `B_electrical` ≈ 0.7 · bitrate — полоса электрического приемника для NRZ

Для упрощенной модели (без учета полосы приемника):
```
SNR ≈ OSNR
```

### Влияние шума на сигнал

Шум добавляется к сигналу как аддитивный белый гауссов шум (AWGN):

```
y(t) = s(t) + n(t)
```

где:
- `s(t)` — полезный сигнал
- `n(t)` — гауссов шум с нулевым средним и стандартным отклонением σ_noise

Стандартное отклонение шума вычисляется из SNR:

```
σ_noise = A_signal / √SNR
```

где `A_signal` — пиковая амплитуда сигнала.

### Влияние на глазковую диаграмму

Шум влияет на "открытость" глаза:

1. **Вертикальное закрытие** — шум уменьшает разницу между уровнями "1" и "0"
2. **Горизонтальное закрытие** — шум на фронтах импульсов создает джиттер
3. **Толщина трасс** — чем выше шум, тем толще линии на диаграмме

**Типичные значения OSNR:**
- OSNR > 25 дБ — отличное качество, глаз широко открыт
- OSNR = 15-25 дБ — приемлемое качество, глаз частично закрыт
- OSNR < 15 дБ — плохое качество, глаз сильно закрыт, высокая вероятность ошибок

## Реализация

### 1. Расширение модели данных

В `core/calculators/dispersion_visualizer.py` добавлены поля в `PulseMetrics`:

```python
@dataclass(frozen=True)
class PulseMetrics:
    # ... существующие поля ...
    
    # SNR параметры для eye diagram
    osnr_db: Optional[float] = None
    snr_linear: Optional[float] = None
```

### 2. Вычисление SNR

В методе `pulse_metrics()` добавлен расчет SNR из OSNR канала:

```python
# Вычисляем SNR из OSNR канала
osnr_db = channel.osnr_db
snr_linear = None
if osnr_db is not None and osnr_db > 0:
    # Преобразуем OSNR (дБ) в линейный SNR
    snr_linear = 10 ** (osnr_db / 10.0)
```

### 3. Добавление шума в eye diagram

В `gui/map_widget.py` метод `_plot_eye_diagram()` модифицирован:

```python
# Вычисляем уровень шума на основе SNR
noise_std = 0.0
if snr_linear is not None and snr_linear > 0:
    # Стандартное отклонение шума: σ_noise = A_signal / √SNR
    noise_std = peak_out / np.sqrt(snr_linear)

# Добавляем гауссов шум к каждой трассе
for y_out in traces_high_out:
    if noise_std > 0:
        noise = np.random.normal(0, noise_std, len(y_out))
        y_out_noisy = y_out + noise
    else:
        y_out_noisy = y_out
    axis.plot(t_axis, y_out_noisy, color="#E53935", linewidth=2.5, alpha=0.7)
```

### 4. Отображение информации о SNR

В информационной панели eye diagram добавлены параметры SNR:

```python
snr_info = ""
if osnr_db is not None:
    snr_info = f"OSNR = {osnr_db:.2f} дБ"
    if snr_linear is not None:
        snr_db = 10 * np.log10(snr_linear) if snr_linear > 0 else 0
        snr_info += f", SNR ≈ {snr_db:.2f} дБ (linear: {snr_linear:.1f})"
    snr_info += "\n"
```

## Примеры использования

### Пример 1: Высокий OSNR (30 дБ)

```
OSNR = 30.00 дБ
SNR (linear) = 1000.00
Noise std = 0.000500
Peak signal = 0.500
```

**Результат:** Глаз широко открыт, трассы тонкие и четкие, минимальное влияние шума.

### Пример 2: Средний OSNR (20 дБ)

```
OSNR = 20.00 дБ
SNR (linear) = 100.00
Noise std = 0.005000
Peak signal = 0.500
```

**Результат:** Глаз частично закрыт, трассы утолщаются, заметное влияние шума.

### Пример 3: Низкий OSNR (10 дБ)

```
OSNR = 10.00 дБ
SNR (linear) = 10.00
Noise std = 0.015811
Peak signal = 0.500
```

**Результат:** Глаз сильно закрыт, трассы очень толстые, высокая вероятность ошибок.

## Физическая корректность

Модель учитывает:

✅ **Аддитивный гауссов шум** — реалистичная модель оптического шума после фотодетектора

✅ **Связь OSNR и SNR** — корректное преобразование из оптической в электрическую область

✅ **Влияние на амплитуду** — шум пропорционален амплитуде сигнала и обратно пропорционален √SNR

✅ **Статистическая природа** — каждая трасса получает независимую реализацию шума

Модель НЕ учитывает (упрощения):

⚠️ **Полосу приемника** — используется упрощенное соотношение SNR ≈ OSNR

⚠️ **Цветной шум** — предполагается белый шум (равномерный спектр)

⚠️ **Нелинейные эффекты** — SPM, XPM, FWM не влияют на шум в данной модели

⚠️ **Фильтрацию** — не учитываются оптические и электрические фильтры
